# Spec: Topic-cluster hardening (NO mass publishing)

**Status**: Active | **Date**: 2026-10-04

## Build (honest subset)
1. Glossary page (~30 standard engineering terms, 1–2 line definitions).
2. Safety overview page (CO/placement/electrical/fuel/kids/pets/storms/911/recalls-via-CPSC-link; explicit suicide-cord warning; NO fake 50-state law table, NO reviewer line).
3. Cluster wiring: hubs + footer + prev/next for the 2 new pages.

## Explicitly refused (fabrication/thin-content risks)
- R1. Sq-ft variants (1,500/2,500/3,000): cannibalize the honest 2,000 page; sq-ft doesn't size — mass variants are doorway content.
- R2. 50-state permit/cost database + cost-by-state/permit-by-state pages: no credible per-state dataset exists; publishing one invents data.
- R3. Owner-survey reliability scores, dealer-density-by-state, brand review pages from "owner data": we hold no such dataset.
- R4. "Reviewed by [Licensed Electrician Name]" line and 9.5-style reviewer badges: no reviewer exists.
- R5. FAQPage schema blocks (15–20 Qs): Google restricts FAQ rich results; visible FAQs stay, schema stays off.
- R6. Universal "20 feet" standby rule: standby clearances are model/manual/AHJ-specific; portables get the 20-ft CPSC guidance, correctly scoped.
- R7. Fabricated installer interview quotes, exact 10-year TCO tables, state CO-law tables, recall database: links to CPSC recall search instead.
- R8. 5,000–7,000-word padded pillars: depth where intent warrants it, never padding for word count.

## Acceptance
- Build + tsc + all QA green; 0 thin/dupe pages; no fake claims; commit+push+deploy.
